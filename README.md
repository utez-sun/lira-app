# LIRA — Мобильное приложение для Android 16 (Трекер Яндекс Музыки)

Мобильное приложение для отслеживания динамики слушателей артиста на **Яндекс Музыке**.

---

## Возможности приложения

1. **Ежедневное автоматическое обновление**:
   - Каждый день в **15:00** (или в любое время, заданное в настройках) фоновая служба Android **WorkManager** опрашивает Яндекс Музыку и сохраняет данные.
   - Работает автономно даже при закрытом приложении, учитывает энергосбережение Doze Mode.
2. **График динамики**:
   - Наглядная сглаженная кривая Безье с градиентной заливкой под графиком.
   - Интерактивные точки: при нажатии на график показываются точные данные за этот день (число слушателей и разница).
3. **Кнопка «Получить данные сейчас»**:
   - Позволяет мгновенно обновить статистику в один клик.
4. **Настройки**:
   - ID артиста (по умолчанию `24578741` — LIRA ULTRA).
   - Точное время ежедневного обновления (часы и минуты). При сохранении фоновая служба автоматически перепланирует время следующего запуска.
5. **Дизайн и иконка**:
   - Фирменный логотип **LU** с коралловым сердцем интегрирован в качестве иконки приложения для всех плотностей экранов Android (`mipmap-hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`).
   - Современный тёмный интерфейс Material 3 (Jetpack Compose).

---

## Архитектура проекта

- **ОС / Target**: Android 16 (API 36), совместимость с Android 8.0+ (minSdk 26).
- **Стек**: Kotlin 2.x, Jetpack Compose, Material 3, AndroidX Room (локальная база данных), AndroidX WorkManager (фоновый планировщик), OkHttp (сетевые запросы).
- **База данных**: Хранит историю (`ListenerRecord`: дата, таймстемп, количество слушателей, дельта с предыдущим днем).

## Как собрать и установить APK на телефон

### Способ 1: Сборка в облаке через GitHub Actions (без установки Android Studio на ПК)
В проекте уже настроен файл [build-apk.yml](file:///C:/Users/utezs/.gemini/antigravity/scratch/LiraApp/.github/workflows/build-apk.yml):
1. Создайте репозиторий на GitHub и загрузите файлы из папки `C:\Users\utezs\.gemini\antigravity\scratch\LiraApp`.
2. Перейдите во вкладку **Actions** в GitHub.
3. GitHub автоматически скомпилирует приложение за 2 минуты и прикрепит готовый файл **`LIRA-Android-App.zip`** (внутри `app-debug.apk`).
4. Скачайте `app-debug.apk` на телефон и установите.

### Способ 2: Через Android Studio
1. Запустите **Android Studio**.
2. Выберите **Open** и укажите папку:
   `C:\Users\utezs\.gemini\antigravity\scratch\LiraApp`
3. Дождитесь завершения Gradle Sync.
4. В меню выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)** или подключите телефон по USB/Wi-Fi и нажмите зеленую кнопку **Run ▶**.
